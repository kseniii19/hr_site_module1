# CLAUDE.md

Статический сайт на чистых HTML/CSS/JS без сборщика, npm и фреймворков. Страницы открываются в браузере напрямую (`open index.html`).

## Структура

```
hr_site1/
├── index.html        # новый сайт (пока пустой каркас)
├── js.js             # скрипты нового сайта
├── css/
│   ├── style.css     # точка входа: только @import остальных файлов
│   ├── reset.css     # сброс стилей
│   ├── font.css      # @font-face
│   ├── content.css   # основные стили (десктоп)
│   └── adaptive.css  # медиазапросы
├── fonts/            # шрифты
├── img/              # изображения (в основном .svg)
└── reference/        # готовый сайт «Тектура» — образец, не редактировать
```

`reference/` содержит законченный многостраничный сайт (index, about, cataloge, product, lab, event, contact, 404) и служит эталоном архитектуры, стиля кода и вёрстки. Новый сайт в корне строится по тем же принципам. Без явной просьбы файлы в `reference/` не меняем.

Отличия корня от образца: в образце шрифты подключаются файлом `fonts.css` (в корне — `font.css`), скрипт лежит в `js/js.js` (в корне — `js.js`), а анимации вынесены в `animation.css`.

## Принципы

### HTML
- `<html lang="ru">`, `meta charset="utf-8"` и `viewport`, контент на русском.
- В `<head>` подключается только `css/style.css`, а он через `@import` подтягивает остальные CSS. Затем CDN-библиотеки и собственный скрипт.
- У каждой страницы `<body id="<имя>-page">` (`main-page`, `about-page`, `cataloge-page`…). По этому id в CSS подсвечивается активный пункт меню.
- Шапка `.main-header` и мобильное меню (`.burger-menu-btn` + `.mobile-menu-panel`) повторяются на каждой странице без изменений.
- Страница делится на блоки `<section class="section1">`, `section2` и так далее.
- Ссылки и пути относительные (`./img/...`, `about.html`).

### CSS
- Все размеры задаются в `vw`, чтобы вёрстка масштабировалась с шириной окна. `px` не используется.
- Порядок подключения в `style.css`: reset, fonts, content, animation, adaptive.
- `content.css` отвечает за десктоп. `adaptive.css` содержит два диапазона:
  - `max-width: 450px` — телефон;
  - От 1366px действуют десктопные стили.
- Шрифты: `"CoFo Sans"` (основной) и `"RFDewi"`, файлы `.ttf` лежат в `fonts/`.
- Классы именуются через нижнее подчеркивание (`text_link`, `author_name`, `section_3`).

### JS
- Один файл скриптов на весь сайт, код обёрнут в `window.addEventListener("load", ...)`.
- Каждый блок сначала проверяет, есть ли нужный элемент на странице (`if (el) { ... }`), потому что скрипт общий для всех страниц.
- Анимации: GSAP + ScrollTrigger, плавный скролл: Lenis. Всё подключается с CDN (cdnjs, unpkg) с фиксированной версией. Для разных экранов используется `gsap.matchMedia()` с теми же брейкпоинтами, что в CSS.
- Комментарии к блокам кода пишутся на русском маленькими буквами (`// 1. анимация цитаты`).

### Ресурсы
- Изображения хранятся в `img/`, преимущественно в формате SVG.
